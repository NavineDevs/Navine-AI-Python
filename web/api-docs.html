Overview

Navine AI - Python exposes a REST API on the local web server (default http://127.0.0.1:8765). Start the server with:

python -m navine.server

All inference runs on the Navine host with Navine-trained weights. Image and video generation do not call third-party model APIs. The website UI runs in your browser on your device.

Authentication

API routes under /api/* and /v1/* require authentication unless the request comes from localhost and allow_localhost_without_auth is enabled (default).

Provide your API key using either header:

Authorization: Bearer YOUR_API_KEY
X-Navine-API-Key: YOUR_API_KEY

Create keys with:

python -m navine.cli api-key create --name "my key"

GET/api/health

Health check. Does not require authentication.

Response

{ "status": "ok" }

Example

curl http://127.0.0.1:8765/api/health

curl http://127.0.0.1:8765/api/info

POST/api/text

Generate text from a prompt using the Navine AI - Python text model.

Request body

{
  "prompt": "Explain local AI in one sentence.",
  "max_tokens": 256,
  "temperature": 0.7
}

Response

{ "text": "..." }
curl -X POST http://127.0.0.1:8765/api/text \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"prompt":"Hello from Navine AI - Python"}'

POST/api/chat

Conversational chat with history support and automatic code intent detection.

Request body

{
  "message": "Write a python function to reverse a string",
  "history": [
    { "user": "Hi", "assistant": "Hello! I am Navine AI - Python..." }
  ],
  "max_tokens": 512,
  "temperature": 0.7,
  "use_rag": true
}

Use a messages array with role and content (common chat API style).

Response

{
  "text": "Here is the python code:\n\n```python\ndef reverse_string(s): ...",
  "message": { "role": "assistant", "content": "..." },
  "is_code": true
}
curl -X POST http://127.0.0.1:8765/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Write a fibonacci function in Python"}'

POST/api/code

Generate code for a specific task and language.

Request body

{
  "task": "Write a function to reverse a string",
  "language": "python"
}

Supported languages: python, javascript, typescript, rust, go, java, cpp

Response

{
  "code": "def reverse_string(s: str) -> str:\n    return s[::-1]",
  "language": "python"
}
curl -X POST http://127.0.0.1:8765/api/code \
  -H "Content-Type: application/json" \
  -d '{"task":"Write a fibonacci function","language":"python"}'

POST/api/image

Generate an image from a text prompt. Uses local diffusion with procedural fallback for simple prompts.

Request body

{
  "prompt": "create me a blue moon",
  "num_steps": 100,
  "guidance_scale": 3.5,
  "seed": 42,
  "enhance": true
}

Response

{
  "path": "outputs/image/generated.png",
  "mime": "image/png",
  "data_base64": "...",
  "enhanced_prompt": "a blue moon in night sky, digital art, high quality..."
}
curl -X POST http://127.0.0.1:8765/api/image \
  -H "Content-Type: application/json" \
  -d '{"prompt":"create me a blue moon","num_steps":100}'

POST/api/video

Generate a short animated GIF from a text prompt.

Request body

{
  "prompt": "waves on a beach",
  "num_frames": 16,
  "fps": 12,
  "seed": 42
}

Response

{
  "path": "outputs/video/generated.gif",
  "mime": "image/gif",
  "data_base64": "..."
}
curl -X POST http://127.0.0.1:8765/api/video \
  -H "Content-Type: application/json" \
  -d '{"prompt":"waves on a beach","num_frames":16,"fps":12}'

POST/v1/chat/completions

Compatible chat-completions endpoint for tools that expect a standard messages API format.

Request body

{
  "model": "navine-text",
  "messages": [
    { "role": "user", "content": "Hello" }
  ],
  "max_tokens": 256,
  "temperature": 0.7
}

Response

{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "created": 1718280000,
  "model": "navine-text",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "..." },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 0, "completion_tokens": 0, "total_tokens": 0 }
}
curl -X POST http://127.0.0.1:8765/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"model":"navine-text","messages":[{"role":"user","content":"Hello"}]}'

Streaming (stream: true) is not supported.
